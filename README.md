## 我的开发方式

> 先理解问题，再构建最小可用版本；用真实使用反馈推动下一轮迭代。

```mermaid
flowchart LR
  A[明确问题与使用场景] --> B[拆解需求与技术约束]
  B --> C[构建最小可用版本]
  C --> D[测试与真实使用]
  D --> E[重构、补充文档与持续迭代]
  E --> A
```
